Who it suits

Good fit

  • Mixed Windows, Mac and Linux estates that want patching, software deployment and remote control in one console
  • Small teams starting out: the free edition covers 25 computers and 25 mobile devices
  • Organisations with many branch offices, thanks to distribution servers and internet-facing agents

Check before you buy

  • The on-premises server only runs on Windows
  • Laptop MDM and the full security toolset only come with the two top editions
  • Extra technicians and security add-ons raise the cost quickly as you grow
