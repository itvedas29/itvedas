    ManageEngine Endpoint Central

    Unified endpoint management and security from ManageEngine, a division of Zoho Corporation. Patching, software deployment, remote control, asset inventory and mobile device management from one console.

    • Formerly Desktop Central
    • Deployment On-premises or cloud
    • Server OS Windows
    • Database PostgreSQL or SQL Server
    • Licensing Per endpoint, yearly or perpetual
    • Free trial 30 days
    35,000computers per server
    4–32 GBserver RAM, by fleet size
    1,100+third-party apps patched
    $0for 25 computers + 25 mobiles

    In plain words

    Every company computer, laptop and phone needs updates, software and protection. Endpoint Central lets one IT team do all of that from a single web page instead of visiting each device. It installs updates, pushes out apps, keeps a list of every device, lets the IT team see a user's screen to help them, and blocks threats like viruses and data leaks.

    A small agent runs on each device and checks in with the server. You can run that server yourself on Windows, or let ManageEngine host it in the cloud.

    Who it suits

    Good fit

    • Mixed Windows, Mac and Linux estates that want patching, software deployment and remote control in one console
    • Small teams starting out: the free edition covers 25 computers and 25 mobile devices
    • Organisations with many branch offices, thanks to distribution servers and internet-facing agents

    Check before you buy

    • The on-premises server only runs on Windows
    • Laptop MDM, OS deployment and the full security toolset only come with the two top editions
    • Extra technicians and security add-ons raise the cost quickly as you grow
