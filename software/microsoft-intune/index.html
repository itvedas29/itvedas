    Microsoft Intune

    Cloud-based unified endpoint management from Microsoft, part of Microsoft 365 and Microsoft Entra. Set up, secure and update company Windows, Mac, phone and Linux devices from the Microsoft Intune admin center, with no server to run.

    • Vendor Microsoft Corporation
    • Deployment Cloud only
    • Admin console Microsoft Intune admin center
    • Identity Microsoft Entra ID
    • Licensing Plan 1, Plan 2, Suite, or included in Microsoft 365
    0servers to run
    6device platform families
    4supported admin browsers
    3licence plans to choose from

    In plain words

    Intune lets an IT team manage company laptops, desktops and phones from a web portal. Devices sign in with a Microsoft Entra account, then receive settings, apps, security rules and updates. If a device stops meeting the rules, it can be blocked from company data.

    There is nothing to install on your own servers. Most organisations already get Intune through a Microsoft 365 plan.

    Who it suits

    • Organisations already on Microsoft 365 or Microsoft Entra ID, which get Intune in the same licence.
    • Teams that want no on-premises management server to build, patch or back up.
    • Fleets that are mostly Windows, with phones and Macs alongside.
    • If you need an on-premises server, Intune is not the right fit. See ManageEngine Endpoint Central, which runs on-premises or in the cloud.
