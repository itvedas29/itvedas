FAQ

Frequently Asked Questions

Do you support Azure AD / Entra ID only, or on-prem AD too?

Both — tell us your setup in the requirement form so we can scope accordingly.

Can you help build a proper offboarding checklist?

Yes, this is one of the more common requests we get, especially from teams that have been burned by an incomplete offboarding before.

Do you need domain admin access?

Only where it's genuinely required for the task, and only for the duration needed.

We're a very small team — is Active Directory overkill for us?

Possibly. If you're under ~10 people, we may recommend a simpler identity setup like Google Workspace or Microsoft Entra ID instead — we'll tell you honestly if AD isn't the right fit.

Ready to fix your Active Directory issue?

Tell us what's going on — we'll review it and get back to you with next steps.
