Delivery Model
Hybrid: On-Premise physical bare-metal / hypervisor VM or Cloud SaaS (Zoho Cloud multi-DC globally).
Protocol Support
HTTPS (TLS 1.3 / 1.2 on port 8383), WebSocket live push (port 8027), WebRTC (port 8443 screen share), LDAPS (636).
Multi-Tenant MSP Support
Native MSP Architecture: Available via dedicated Endpoint Central MSP edition with tenant boundary isolation.
WAN Distribution Architecture
Hub-and-Spoke Topology: Branch office Distribution Server caches packages locally with bandwidth throttling to prevent WAN saturation.
High Availability / Failover
Active-Passive Failover Server with secondary IP takeover (<60s heartbeat); automated database replication.
Secure Gateway Server (DMZ)
Reverse proxy gateway in perimeter DMZ for remote off-VPN roaming agent check-in without exposing internal LAN ports.
NAT Traversal
Built-in STUN / TURN relay service for out-of-band remote control & patch broadcast.
Windows Desktop
Windows 11 (24H2, 23H2, 22H2, 21H2 — Pro, Enterprise, Education, SE), Windows 10 (32/64-bit, LTSC/LTSB), Windows 8.1, 7 SP1.
Windows Server
Windows Server 2025, 2022, 2019, 2016, 2012 R2, 2008 R2 SP1 (Both Full Desktop Experience and Server Core).
macOS Architecture
macOS 15 Sequoia, macOS 14 Sonoma, 13 Ventura, 12 Monterey, 11 Big Sur — Native Apple Silicon (M1-M4) & Intel universal binaries.
Linux Distributions
Ubuntu (18.04 - 24.04 LTS), RHEL (7-9), Debian (10-12), CentOS Stream, Rocky Linux, AlmaLinux, SUSE SLES, openSUSE, Fedora.
Mobile & Tablets (MDM)
iOS/iPadOS 14 to 18+, tvOS 14+; Android 9.0 to 15 (Google Android Enterprise Recommended partner).
ChromeOS & IoT
ChromeOS Enterprise enrollment via Google Workspace API; single/multi-app kiosk lockdown and lost-device geo-tracking.
Minimum CPU (Server)
4 Cores (Intel Xeon or AMD EPYC / modern x86-64 equivalent @ 2.4 GHz).
Recommended CPU
8 to 16 Cores for environments managing 5,000 to 25,000 active nodes.
Server RAM Scaling
8 GB (≤1,000 nodes) • 16 GB (1,000 - 5,000 nodes) • 32-64 GB (5,000 - 25,000+ nodes).
Database Engine Backend
PostgreSQL 14+ (Bundled default; zero added cost, up to 10K nodes) or MS SQL Server (2014 to 2022 Standard/Enterprise for >10K nodes).
Storage IOPS & Space
100 GB OS installation; 250 GB - 2 TB SSD repository for patch binaries; min 1,500 IOPS SSD recommended.
Agent Memory Footprint
~35 MB - 50 MB RAM idle; <1.5% background CPU scan with network bandwidth throttling limits.
3rd-Party Patch Catalog
850+ Pre-Tested Applications across Windows and macOS (Adobe, Chrome, Zoom, Firefox, Slack, VLC, Teams, Edge, etc.) with test & approve automation.
Silent Deployment Formats
MSI, EXE, MSP, MSU, PKG, DMG, APPX, DEB, RPM, PowerShell (`.ps1`), VBScript, Batch scripts, Bash. 8,000+ pre-built templates in software library.
Remote Desktop Protocols
Integrated HTML5 WebRTC remote control (clientless for technicians); multi-monitor switching, file transfer, HIPAA session recording.
OS Bare-Metal Imaging
Automated bare-metal deployment via PXE network boot & USB media; hardware-independent imaging with automated driver injection.
Asset & License Metering
Real-time hardware inventory, warranty tracking, prohibited software auto-uninstallation, software usage metering to eliminate underutilized seats.
SSO / SAML 2.0 Providers
SAML 2.0 integration tested with Entra ID, Okta, PingIdentity, OneLogin, Google Workspace, CyberArk, JumpCloud; SCIM 2.0 auto-provisioning.
MFA Types Supported
TOTP (Google / Microsoft Authenticator), Email OTP, SMS verification, Duo Security push, RADIUS server integration.
RBAC Granularity
Discrete custom permission scoping down to individual computer groups and action boundaries (e.g. Remote Control Only).
Encryption Standards
TLS 1.3 / 1.2 in transit; AES-256 column-level encryption at rest for credentials and BitLocker recovery keys.
Compliance Accreditations
SOC 2 Type II ISO 27001:2022 HIPAA GDPR FedRAMP Moderate (Cloud)
ITSM Ecosystem
ServiceDesk Plus: 100% Native zero-code bidirectional sync • ServiceNow: Certified Store application • Jira Service Management: Native marketplace plugin.
SIEM & Observability
Syslog & CEF event forwarder to Splunk, Log360, Datadog, Elastic Stack, and Microsoft Sentinel for real-time security alerts.
REST API Architecture
Comprehensive RESTful API v2 with OpenAPI 3.0 / Swagger documentation; API token authentication with rate-limiting controls.
Automation & SDKs
PowerShell SDK module (`EndpointCentral-PS`), Python automation scripts, and Webhooks for event-driven orchestration.
