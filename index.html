Who it suits

Good fit

  • Mixed Windows, Mac and Linux estates that want one console for patching, software deployment and remote control
  • Small teams: the free edition covers 25 computers and 25 mobile devices
  • Sites with many branch offices, thanks to distribution servers and internet-facing agents

Check before buying

  • The on-prem server needs Windows
  • Laptop MDM and full security features only come with the two top editions
  • Extra technicians and security add-ons raise the cost quickly as you grow
