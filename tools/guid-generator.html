    🎰 GUID / UUID Generator

    Generate cryptographically random version-4 UUIDs (GUIDs) for applications, databases, and distributed systems. Uses the browser's secure random source — nothing is transmitted.

    A version-4 UUID is a 128-bit identifier with 122 random bits, giving roughly 5.3 × 1036 possible values — collisions are astronomically unlikely, which is why UUIDs are used as primary keys, correlation IDs, and idempotency tokens without a central authority.
