🔍 WHOIS Lookup

Real, live domain registration data — queried directly from the registry's WHOIS server, not sample data.

WHOIS Information


    


    

      
Quick Answer

      
WHOIS is a protocol for looking up domain registration details — registrar, registration/expiration dates, and name servers. This tool queries the actual authoritative WHOIS server for your domain in real time and returns its live record, both as a parsed summary and the full raw response.


      
What is WHOIS?

      
Every registered domain has a WHOIS record maintained by its registry and registrar, showing who registered it, when, and which name servers it uses. Since GDPR and similar privacy regulations, many registrars now redact personal registrant details by default — this is normal and doesn't mean the lookup failed.


      
How this tool works

      
ITVEDAS's own edge server asks IANA's root WHOIS server which registry runs your domain's TLD, queries that registry over the WHOIS protocol (port 43), and — for TLDs like .com/.net that use a "thin" registry model — follows the referral to the registrar's own WHOIS server for the full record. It never connects anywhere except official WHOIS servers discovered through that chain.


      
Privacy

      
Your query goes to ITVEDAS's own server, which relays it to the relevant WHOIS servers on your behalf — your browser never connects to them directly. Nothing you search is logged or stored.


      
FAQ

      

        
Why don't I see a registrant name or email?

        
Most registrars redact this by default under GDPR/ICANN privacy policies. This is expected — it's not a failed lookup.

      

      

        
Why does a subdomain show "No match"?

        
WHOIS only has records for registered domains, not subdomains — look up example.com, not www.example.com.

      

      

        
Some fields are missing from the summary — why?

        
Every registry formats its WHOIS output slightly differently, and the summary only extracts commonly-used field names. The full raw record (toggle above) always has everything the server returned, even if the summary parser didn't recognize a particular line.

      

      

        
Why did the lookup fail for my TLD?

        
A handful of TLDs don't run a classic WHOIS service (some rely on RDAP only, or restrict access). If that happens, try ICANN Lookup instead.
