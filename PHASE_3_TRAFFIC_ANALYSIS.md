## Success Criteria

**STRONG SUCCESS (Target 30-50%+ growth)**
- Organic sessions increase 30%+ compared to pre-fix
- Pages per session up 15%+
- Bounce rate down 10%+
- New keywords ranking in top 10

**MODERATE SUCCESS (15-30% growth)**
- Organic sessions increase 15-30%
- Pages per session stable or slightly up
- No significant bounce rate change
- Slowly ranking for more keywords

**MINIMAL SUCCESS (<15% growth)**
- Organic sessions increase <15%
- Requires investigation
- Possible causes: GSC issues, crawl errors, ranking delays

**FAILURE (Decline)**
- Organic traffic decreases
- Immediate investigation required
- Potential issues: Penalties, technical problems, GSC errors

## Troubleshooting Guide

### If traffic isn't increasing after 1 week:
1. Check GSC > Coverage: Are pages still being indexed?
2. Check Search Console > Indexing Issues: Any new errors?
3. Verify sitemap: Was it properly submitted?
4. Check robots.txt: Any blocks preventing indexing?

### If bounce rate increased:
1. Review top pages for UX issues
2. Check page speed: Did something get slower?
3. Review content: Is it matching search intent?
4. Check internal links: Are users finding related content?

### If certain keywords aren't ranking:
1. Verify content has these keywords (natural usage)
2. Check keyword difficulty: Is it realistic to rank?
3. Assess competitor positioning
4. Check backlink profile for authority
