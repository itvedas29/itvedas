# Security Policy

ITVedas (itvedas.com) is a static educational website. This repository holds site content and the automation that publishes it. There are no user accounts, no payment processing, and no user-submitted data stored server-side.

## Reporting a Vulnerability

If you find a security issue, such as an XSS vector in published content, a leaked credential, a misconfigured GitHub Actions workflow, or a supply chain issue in a dependency, please report it privately rather than opening a public issue.

Preferred method: use GitHub's private vulnerability reporting for this repository, found under the Security tab, Report a vulnerability.

Alternative method: email info@itvedas.com with details and steps to reproduce. Please include as much detail as possible: affected file or URL, reproduction steps, and potential impact.

## Response

This is a solo maintained project. Reports are reviewed as soon as possible on a best effort basis; there is no guaranteed SLA. Valid reports will be fixed and credited if desired once resolved.

## Scope

In scope: this repository's code, GitHub Actions workflows, and the published itvedas.com site. Out of scope: third party services the site links to or embeds, such as Cloudflare, Google Analytics, or external CDNs.
